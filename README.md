# UEFA Draw Simulator

A web application for simulating UEFA tournament draws including Champions League, Europa League, and Conference League.

## Description

This application allows users to simulate realistic UEFA tournament draws with proper group formations and constraints. It includes support for multiple competitions and provides a user-friendly interface for conducting draws.

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Features

- [x] UEFA Champions League draw simulation
- [x] UEFA Europa League draw simulation  
- [x] UEFA Conference League draw simulation
- [x] Multi-language support (Turkish/English)
- [x] Draw history tracking
- [x] Responsive design
- [x] TypeScript support
